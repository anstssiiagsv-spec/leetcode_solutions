Задача: Longest substring without repeating characters
Сложность: Medium
Дана строка s. Нужно найти длину самой длинной подстроки, в которой символы не повторяются.

Для решения я использую unordered_set.
У окна есть две границы: left и right. Указатель right двигается по строке и добавляет новые символы.
В seen хранятся символы.
Если символ s[right] уже есть в seen, значит появился повтор. Тогда с помощью while я удаляю символы с левой стороны окна и двигаю left, пока повтор не исчезнет.
После этого добавляю текущий символ в seen.
Длина текущего окна вычисляется так: right - left + 1
После каждого шага сравниваю длину текущего окна с maxLength и сохраняю максимальное значение.
