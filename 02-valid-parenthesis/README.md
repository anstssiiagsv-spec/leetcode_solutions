Задача: Valid Parenthesis
Сложность: Easy
Дана строка s, содержащая скобки (), [] и {}. Нужно определить, правильно ли расставлены скобки.

Для решения я использую `stack`, потому что он позволяет работать с последним добавленным элементом. Последняя открытая скобка должна закрыться первой.
Я прохожу по строке слева направо. Если встречаю открывающую скобку, добавляю её на вершину стека с помощью `push()`.
Если встречаю закрывающую скобку, сначала проверяю, не пуст ли стек. Если стек пуст, возвращаю `false`, потому что для закрывающей скобки нет соответствующей открывающей.
Затем с помощью `top()` проверяю верхний элемент стека. Если открывающая и закрывающая скобки не образуют пару, возвращаю `false`.
Если скобки образуют правильную пару, с помощью `pop()` удаляю верхний элемент стека.
После обработки всей строки проверяю, пуст ли стек. Если он пуст, значит все открывающие скобки нашли свои закрывающие пары. Если в стеке остались элементы, значит некоторые скобки не были закрыты.
