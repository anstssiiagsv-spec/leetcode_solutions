Задача: Merge k Sorted Lists
Сложность: Hard

Дано несколько отсортированных связанных списков. Нужно объединить их в один отсортированный связанный список.

Для решения я использую priority_queue с минимальным элементом наверху.
Сначала добавляю в priority_queue первый узел каждого непустого списка. Так как каждый исходный список уже отсортирован, минимальный элемент среди этих узлов будет минимальным среди всех ещё не обработанных элементов.
Для сравнения узлов используется Compare, который сравнивает их значения val.
Пока priority_queue не пустая:
1. С помощью top() получаю узел с минимальным значением.
2. Удаляю его из очереди с помощью pop().
3. Сохраняю его следующий узел node->next.
4. Добавляю текущий узел в результирующий список.
5. Если следующий узел существует, добавляю его в priority_queue.
Для построения результата использую два указателя:
- result всегда указывает на первый узел итогового списка.
- last указывает на последний добавленный узел.
Когда добавляется первый элемент, result и last указывают на один и тот же узел. Для следующих элементов новый узел присоединяется через last->next, после чего last передвигается на него.
В конце возвращаю result, потому что он указывает на начало полностью объединённого списка.
