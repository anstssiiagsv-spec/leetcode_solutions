Задача: Two Sum
Сложность: Easy
Дан массив целых чисел nums и целое число target. Нужно найти индексы двух разных элементов, сумма которых равна target.

Первый способ решения - это перебрать все возможные пары элементов с помощью двух вложенных циклов. Но сложность такого решения O(n^2).
Чтобы получить сложность O(n), я использую unordered_map seen, в которой храню значение просмотренного элемента массива и его индекс.
Для каждого элемента массива вычисляю needed = target - nums[i].
Затем проверяю есть ли значение needed в seen - если да, то нужная пара найдена, тогда возвращаем нужные индексы. 
Если нет, то сохраним текущий элемент в seen.
